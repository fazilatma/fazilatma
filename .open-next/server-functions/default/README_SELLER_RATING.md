# سیستم امتیازدهی فروشندگان OptiBid

## هدف

امتیاز فروشنده از ۱۰۰ محاسبه می‌شود و برای رتبه‌بندی، نمایش سطح اعتماد و هشدارهای عملکرد استفاده می‌گردد. دوره ارزیابی اصلی ۹۰ روز اخیر است. فروشنده جدید با داده ناکافی در سطح «در حال ارزیابی» باقی می‌ماند و وارد رتبه‌بندی عمومی نمی‌شود.

## وزن معیارها

| معیار | وزن | داده‌های اصلی |
|---|---:|---|
| قابلیت اتکا و کیفیت معامله | ۳۰٪ | نرخ نقص سفارش، لغو فروشنده، اختلاف حل‌نشده، مغایرت موجودی و بازگشت تقصیر فروشنده |
| ارسال و تحویل | ۲۵٪ | ارسال به‌موقع، رهگیری معتبر، تاخیر ارسال |
| رضایت و پاسخ‌گویی | ۲۵٪ | میانگین تعدیل‌شده نظرات، پاسخ اولیه در ۲۴ ساعت، متوسط زمان پاسخ |
| اعتماد و انطباق | ۱۲٪ | احراز هویت، حساب بانکی، مدارک کسب‌وکار و تخلفات باز |
| سابقه و فعالیت | ۸٪ | معامله تکمیل‌شده، تکمیل پروفایل و فعالیت ۳۰ روز اخیر |

## جلوگیری از رتبه‌بندی ناعادلانه فروشنده تازه‌وارد

- امتیاز نظرها با **میانگین بیزی** محاسبه می‌شود؛ یک نظر ۵ ستاره نمی‌تواند فروشنده جدید را بالاتر از فروشنده باسابقه قرار دهد.
- برای ورود به رتبه‌بندی عمومی، حداقل ۵ معامله تکمیل‌شده در ۹۰ روز، ۳ نظر، احراز هویت و تایید حساب تسویه لازم است.
- `confidence` نشان می‌دهد درصد اعتبار داده‌ها چقدر است؛ رتبه با داده کم نباید به عنوان رتبه قطعی تلقی شود.

## منابع طراحی معیارها

- eBay Seller Standards: نقص معامله، لغو، پرونده حل‌نشده، ارسال دیرهنگام و ارزیابی منصفانه بر اساس حجم معاملات.
  - https://www.ebay.com/help/policies/selling-policies/seller-standards-policy?id=4347
- Etsy Star Seller: پاسخ اولیه ۹۵٪ در ۲۴ ساعت، ارسال به‌موقع با رهگیری ۹۵٪ و میانگین نظر ۴.۸.
  - https://www.etsy.com/starseller
- Amazon Seller Performance / Valid Tracking: نرخ نقص سفارش، لغو پیش از ارسال، تاخیر ارسال و رهگیری معتبر.
  - https://sellercentral.amazon.com/seller-forums/discussions/t/47b88bec-761c-4f14-9c0b-60ecc9603d8d

## APIهای مرتبط

- `GET /api/seller-score?sellerId=ID` — گزارش امتیاز یک فروشنده.
- `PATCH /api/admin/seller-metrics` — بروزرسانی متریک‌ها توسط ادمین.
- `PATCH /api/seller/profile` — ذخیره Bio و دسته‌بندی‌های فعالیت فروشنده.
- `POST /api/seller-performance-event` — ثبت رویداد عملکرد و محاسبه مجدد امتیاز.

### رویدادهای عملکرد خودکار

| event | زمان فراخوانی |
|---|---|
| `order_completed` | وقتی خریدار دریافت کالا را تایید می‌کند |
| `shipment_created` | وقتی فروشنده کد رهگیری و وضعیت ارسال را ثبت می‌کند |
| `seller_cancellation` | وقتی فروشنده سفارش را پیش از ارسال لغو می‌کند |
| `buyer_review` | وقتی خریدار نظر و امتیاز ثبت می‌کند |
| `first_message_response` | بعد از پاسخ اولیه فروشنده به پیام خریدار |
| `unresolved_case` | وقتی اختلاف به نفع خریدار و بدون حل توسط فروشنده بسته می‌شود |
| `seller_fault_return` | وقتی بازگشت کالا به تقصیر فروشنده ثبت می‌شود |
| `dispute_against_seller` | وقتی رای اختلاف علیه فروشنده است |
| `verification_updated` | هنگام تایید هویت، حساب تسویه یا مدارک کسب‌وکار توسط ادمین |
