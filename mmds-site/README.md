# MMDS — سایت مستقل PHP

این نسخه، کد تک‌فایلی دریافت‌شده از Google Drive است. برای اینکه از اپ Next.js مخزن جدا بماند، در پوشهٔ `mmds-site/` نگهداری می‌شود.

## اجرا در محیط دارای PHP

از ریشهٔ مخزن اجرا کنید:

```bash
php -S 0.0.0.0:8000 -t mmds-site
```

سپس سایت را در مرورگر روی پورت 8000 باز کنید. برای انتشار، فایل `index.php` را در هاست PHP (مثلاً پوشهٔ `public_html`) قرار دهید.

## ساختار فایل‌ها

- `index.php`: صفحهٔ اصلی، تحلیل سیگنال مرورگر/کلاینت، ضبط زنده و بخش پاکسازی اختیاری نویز، واسط ثبت‌نام و ورود، و Service Worker.
- `auth.php`: API ثبت‌نام، ورود، مدیریت سشن و احراز هویت دومرحله‌ای (پیامک ملی‌پیامک و Gmail SMTP).
- `schema.sql`: ساختار جدول‌های MySQL برای کاربران و ثبت‌نام‌های در انتظار تأیید.
- `AUTH_SETUP.md`: راهنمای متغیرهای محیطی هاست و فعال‌سازی امن ثبت‌نام و پیامک/ایمیل.

## نکته

تحلیل سیگنال و ضبط موتور مستقیماً در مرورگر انجام می‌شود و حتی بدون لاگین یا به‌صورت آفلاین کار می‌کند. برای فعال‌سازی بخش حساب کاربری (ثبت‌نام با پیامک و ایمیل)، راهنمای `AUTH_SETUP.md` را روی هاست PHP اعمال کنید.
