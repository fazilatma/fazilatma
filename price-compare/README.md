# قیمت‌یار پرو 🦅 — موتور شکار قیمت (خزنده + تحلیل خرید/فروش)

وب‌اپ فول‌استک **Next.js** که مثل یک موتور جستجو/خزشگر (شبیه ترب/گوگل) قیمت‌ها را از چند منبع می‌خزد، برای **خرید و فروش دراپشیپینگ** تصمیم می‌سازد و روند بازار را **رصد و هشدار** می‌دهد.

## منابع (Connector-based)
| منبع | وضعیت | توضیح |
|---|---|---|
| ترب | تلاش برای API واقعی → fallback نمایشی | از IP خارج از ایران مسدود است؛ روی سرور ایرانی واقعی می‌شود |
| دیجی‌کالا | تلاش برای API واقعی → fallback نمایشی | مشابه بالا |
| باسلام | تلاش برای API واقعی → fallback نمایشی | مشابه بالا |
| Google Shopping | با `SERPAPI_KEY` واقعی می‌شود | اسکرپ مستقیم گوگل خلاف ToS و پرکپچاست |
| **تلگرام** | ✅ **واقعی** | خواندن کانال‌های عمومی از t.me/s/… + استخراج قیمت فارسی («۱۲٬۴۰۰٬۰۰۰ تومان»، «24500000ت»)؛ کانال‌ها: `?tg=ch1,ch2` یا `TG_CHANNELS` |
| اینستاگرام | اسکلت آماده + نمایشی | با Instagram Graph API (`IG_ACCESS_TOKEN`) فعال می‌شود |

هر منبع در UI با برچسب **✓ واقعی / ◆ نمایشی / ✕ خطا** نمایش داده می‌شود.

## قابلیت‌ها
- 🔍 **خزش موازی در ۶ منبع** با نرمال‌سازی و ادغام پیشنهادها
- 🛒 **بهترین نقطه‌ی خرید**: کمترین نرخ مؤثر (قیمت + اعتبار فروشنده)
- 💰 **تحلیل فروش دراپشیپینگ**: قیمت پیشنهادی فروش (پرسنتایل ۷۰)، کارمزد، ارسال، **سود خالص و ROI**
- 🔥 **سیگنال تقاضا**: از روی تغییر عرضه‌کننده/قیمت بین مشاهدات (تخمینی و صادقانه برچسب‌خورده)
- 🛎️ **قوانین هشدار**: کاهش قیمت 📉 / جهش قیمت-تقاضا 📈 / کمبود عرضه 🧲 — با «بررسی هشدارها» ری‌استاک می‌شود؛ اسنپ‌شات‌ها در `data/snapshots.json`
- 🧾 جدول کامل پیشنهادها با درصد اختلاف با کف بازار

## API
```
GET /api/hunt?q=آیفون&tg=chan1,chan2&feePct=9&shipCost=150000
GET /api/alerts                # لیست قوانین و رویدادها
POST /api/alerts               # {query, type: drop|spike|supply, thresholdPct}
DELETE /api/alerts?id=…
GET /api/alerts?check=1        # بررسی قوانین (hunt تازه + سنجش با اسنپ‌شات قبلی)
```

## اجرا
```bash
npm install
TG_CHANNELS=mydealchannel,offers npm run dev
```
